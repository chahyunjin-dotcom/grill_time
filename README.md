# 🔥 고기굽기 – 마우스 연습 게임

초등 저학년 어린이가 **마우스 클릭과 드래그(끌어서 놓기)** 를 재미있게 연습할 수 있는 웹 게임입니다.
돼지고기, 소시지, 새우, 오징어, 문어를 불판에 올려 노릇노릇 구워 접시에 담아 보세요!

> 🎮 **바로 해보기:** https://chahyunjin-dotcom.github.io/grill_time/

## 이렇게 해요

1. **끌어서 놓기** – 왼쪽 재료를 마우스로 끌어서 불판 동그라미 위에 올려요.
2. **클릭** – 한쪽이 익으면 재료가 통통 튀어요. 클릭해서 뒤집어요.
3. **끌어서 옮기기** – 양쪽이 다 익으면 끌어서 접시에 놓아요.
4. **치우기** – 너무 오래 두면 타요. 탄 재료는 클릭하면 치워져요.

초록 막대가 가득 차면 익었다는 뜻이에요. 화면 위 안내 문구가 단계마다 바뀌어서 읽으며 따라 할 수 있어요.

## 레벨

| 레벨 | 불판 | 재료 | 목표 |
|---|---|---|---|
| 1 | 4개 | 🥩 돼지고기 | 6개 |
| 2 | 4개 | 🥩 돼지고기 + 🌭 소시지 | 8개 |
| 3 | 4개 | 🥩 돼지고기 + 🌭 소시지 + 🦐 새우 | 10개 |
| 4 | 6개 | 🥩 돼지고기 + 🌭 소시지 + 🦐 새우 + 🦑 오징어 + 🐙 문어 | 12개 |

재료마다 한쪽이 익는 시간이 달라요. (돼지고기 5초 / 소시지 4초 / 새우 3초 / 오징어 4초 / 문어 6초)
레벨이 오를수록 재료가 늘어나고, 레벨 4에서는 불판도 6개로 늘어나요.

목표를 채우면 레벨 업 화면이 나오고, 레벨 4를 끝내면 완료 화면이 나와요.

## 특징

- **마우스 기본 동작 연습:** 클릭과 드래그만 사용해요. 더블클릭이나 우클릭은 필요 없어요.
- **지글지글 효과음:** 불판 위 재료가 많을수록 소리가 커져요. 우측 상단 🔊 버튼으로 끌 수 있어요.
- **실사 스타일 재료 그림:** 모두 SVG로 그려서 이미지 파일이 따로 필요 없어요.
- **터치 화면 지원:** 태블릿에서도 작동해요.
- **다크 모드 지원:** 기기 설정에 맞춰 배경색이 바뀌어요.
- **설치 불필요:** HTML 파일 하나로 되어 있고 외부 라이브러리를 쓰지 않아요.

## 실행 방법

### 내 컴퓨터에서

`index.html` 파일을 더블클릭해서 브라우저(Chrome, Edge, Safari 등)로 열면 바로 실행돼요.

### GitHub Pages로 배포

1. 이 저장소를 Public으로 만들고 `index.html`을 올려요.
2. **Settings → Pages**에서 Source를 `Deploy from a branch`로 선택해요.
3. Branch는 `main`, 폴더는 `/ (root)`를 고르고 **Save**를 눌러요.
4. 1~2분 뒤 `https://chahyunjin-dotcom.github.io/grill_time/` 에서 접속할 수 있어요.

## 난이도 조절

`index.html`의 `<script>` 안에서 아래 값을 바꾸면 돼요.

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 재료별 익는 시간 | `FOODS` 안의 `sec` (작을수록 빨리 익어요) |
| 레벨별 재료, 불판 개수, 목표 개수 | `LEVELS` 안의 `foods`, `slots`, `goal` |
| 타기까지 걸리는 시간 | `BURN` (기본 1.8, 클수록 늦게 타요) |

## 사용 기술

- HTML, CSS, JavaScript (프레임워크 없음)
- Pointer Events (마우스와 터치 공통 처리)
- Web Audio API (지글지글 소리와 효과음)
- 인라인 SVG (재료 그림)

## 참고
